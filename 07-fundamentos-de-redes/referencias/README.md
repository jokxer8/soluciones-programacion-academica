## En palabras simples

![En palabras simples · Guía para estudiantes](../../assets/readme-banners/en-palabras-simples.svg)

Las guías explican los temas con otras palabras. Para abrir actividades oficiales o instalar Packet Tracer, usa la fuente original. Un archivo de práctica no demuestra por sí solo que la prueba se ejecutó.

## Ruta de consulta

| Tema | Qué se estudia | Recurso |
|---|---|---|
| Redes y simulación | Roles, interfaces, modos lógico y físico, medios y topologías | [Cisco Networking Academy: introducción a Packet Tracer](https://www.netacad.com/courses/getting-started-cisco-packet-tracer/1000) |
| IPv4 y subredes | Separar red/host, asignar prefijos y revisar rangos | [Actividad de subnetting](../actividades/09-subnetting/README.md) · [RFC 1918](https://www.rfc-editor.org/rfc/rfc1918) |
| IPv6 y pruebas locales | Prefijos, vecinos y alcance dentro de una LAN | [RFC 8200](https://www.rfc-editor.org/rfc/rfc8200) · [Validación del proyecto](../proyecto-cadena-hotelera/validacion.md) |
| Protocolos de transporte | Confiabilidad, flujo, datagramas y puertos | [RFC 9293 (TCP)](https://www.rfc-editor.org/rfc/rfc9293) · [RFC 768 (UDP)](https://www.rfc-editor.org/rfc/rfc768) |
| Enrutamiento | Rutas estáticas, RIPv2 y camino alternativo | [RFC 2453](https://www.rfc-editor.org/rfc/rfc2453) |
| Consulta bibliográfica | Tanenbaum y Wetherall, *Computer Networks*, 5.ª ed. | [Ficha de Pearson](https://www.pearsoned.co.in/prc/book/andrew-s-tanenbaum-computer-networks-5e--5/9789332518742) |

La carpeta de estudio incluye materiales sobre IOS, protocolos y modelos, capa física, WAN, capa de enlace, conmutación Ethernet, DHCP y direccionamiento. La colección CCNA también contiene recursos sobre ARP, descubrimiento de vecinos, IPv6, ICMP y Wireshark. Son materiales de consulta, no una lista de ejercicios entregados ni una certificación.

## Criterios de publicación

Los textos y diagramas se redactaron como material independiente. Se citan las fuentes oficiales en lugar de distribuir el libro, el instalador, las plantillas de evaluación, las hojas de Cisco, las presentaciones sin licencia de redistribución comprobada ni los cuestionarios. Se describen las entregas colaborativas sin copiar guiones de terceros ni incluir datos identificativos o credenciales. Los archivos de simulación quedan fuera de esta edición porque no se revisaron internamente ni se preparó una copia libre de datos de acceso.
