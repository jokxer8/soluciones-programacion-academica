## En palabras simples

![En palabras simples · Guía para estudiantes](../../assets/readme-banners/en-palabras-simples.svg)

Las guías explican los temas con otras palabras. Para abrir actividades oficiales o instalar Packet Tracer, usa la fuente original. Un archivo de práctica no demuestra por sí solo que la prueba se ejecutó.

Para descargar los documentos públicos, abre [Documentos y evidencias](../recursos/README.md). Los materiales distinguen trabajo de clase, ediciones públicas y ejercicios nuevos.

La carpeta de estudio incluye materiales sobre IOS, protocolos y modelos, capa física, WAN, capa de enlace, conmutación Ethernet, DHCP y direccionamiento. La colección CCNA también contiene recursos sobre ARP, descubrimiento de vecinos, IPv6, ICMP y Wireshark. Son materiales de consulta, no una lista de ejercicios entregados ni una certificación.

## Criterios de publicación

Se publican trabajos de clase atribuidos, extractos revisados de evidencias y material de estudio redactado para el portafolio. Las presentaciones de consulta y plantillas de terceros se sustituyen por guías y ejemplos propios con referencias. No se distribuyen el libro, el instalador, los bancos de terceros, credenciales ni binarios Packet Tracer cuya configuración no se haya revisado. Sí se incluyen las consignas docentes y las entregas revisadas en el [archivo de la materia](../archivo/README.md). La autoría de las exposiciones y del proyecto se conserva.
