Úsala solo en el simulador.

No se adjuntan los cinco archivos de actividad `.pka`: incluyen la red y la rúbrica de evaluación. Uno coincide byte por byte con la plantilla de la colección CCNA. Para esos temas, consulta las [observaciones de laboratorio](../tareas/README.md#laboratorios).
