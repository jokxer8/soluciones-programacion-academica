La consola deja hablar con el equipo aunque todavía no tenga IP. El indicador cambia según lo que puedes consultar o configurar.

## Qué se trabajó

Identifica el acceso de usuario (>) y el privilegiado (#). Usa la ayuda contextual «?» para saber qué admite el modo actual. El ejercicio también practica cómo consultar el reloj y reconocer comandos incompletos.

## Evidencia y alcance

**Material localizado:** Lab 2.1, componente 2.3.7: PDF, DOCX y actividad local.

La entrega combina material de Cisco y anotaciones. Se documenta el aprendizaje, no se reparte la actividad ni se afirma que todas las respuestas quedaron registradas.
