## En palabras simples

![En palabras simples · Guía para estudiantes](../../../assets/readme-banners/en-palabras-simples.svg)

El switch puede tener una dirección fija para administrarlo mientras las computadoras reciben su configuración automáticamente.

## Qué se trabajó

Distingue IP fija de administración frente a concesión a clientes. Comprueba que el cliente ha recibido una dirección coherente con su segmento. Un ping verificable a un equipo del laboratorio complementa, pero no reemplaza, la revisión de esos parámetros.

## Evidencia y alcance

**Material localizado:** Consigna, enlace de repaso y archivo .pkt local.

La consigna y el simulador pueden contener credenciales didácticas construidas con una identificación. Se proponen fichas limpias, no el material bruto.
