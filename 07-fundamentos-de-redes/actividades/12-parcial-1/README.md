## En palabras simples

![En palabras simples · Guía para estudiantes](../../../assets/readme-banners/en-palabras-simples.svg)

Cada oficina tiene su red local. Para conversar con otra oficina, sus equipos envían los datos al router.

## Qué se trabajó

Ficha de competencias: distinguir direcciones fijas frente a DHCP, revisar el gateway, convertir octetos y verificar el paso entre redes usando una topología de ensayo propia.

## Evidencia y alcance

**Material localizado:** Consigna docente, respuestas individuales y simulación .pkt.

No se adjuntan el examen, las respuestas, los datos identificativos ni el simulador. No se afirma calificación ni conectividad de todas las oficinas.
