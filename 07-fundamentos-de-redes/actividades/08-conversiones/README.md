## En palabras simples

![En palabras simples · Guía para estudiantes](../../../assets/readme-banners/en-palabras-simples.svg)

Son distintas formas de escribir el mismo número. En redes esto aparece en octetos IPv4, máscaras y direcciones MAC.

## Qué se trabajó

Ejemplo nuevo: 42 representa 00101010 en binario de ocho bits y 2A en hexadecimal. Suma 32 + 8 + 2 para verificar el binario. Cada dígito hexadecimal equivale a cuatro bits.
