# Práctica 08 — Tablas hash y colisiones

[Materia 04](../README.md) · [Índice de prácticas](../MATERIALES.md) · [Práctica 07 ←](../practica-07/README.md) · [Práctica 09 →](../practica-09/README.md)

## Propósito

Comprender cómo se insertan y localizan claves, y cómo una estrategia de resolución de colisiones afecta a la tabla.

## Mandato

La actividad practica funciones hash, módulo, encadenamiento, sondeo lineal y cuadrático, doble hashing y hashing extensible.

## Qué se trabaja

Construcción de tablas y resolución de colisiones mediante varios métodos.

## Qué aporta esta actividad

Comprender cómo se insertan y localizan claves, y cómo una estrategia de resolución de colisiones afecta a la tabla. El aprendizaje esperado es razonar sobre el método y justificar el resultado, no solo registrar una respuesta. Esta ficha enlaza el material disponible y señala sus límites para que se entienda qué permite comprobar.
