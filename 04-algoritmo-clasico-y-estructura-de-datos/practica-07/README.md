## Propósito

Comparar dos estrategias para conectar los vértices con coste total mínimo y justificar la selección de aristas.

## Mandato

La actividad solicita construir árboles de expansión mínima con Prim y Kruskal sobre cinco grafos.

## Qué se trabaja

Aplicación de Prim y Kruskal a instancias representadas gráficamente.

## Qué aporta esta actividad

Comparar dos estrategias para conectar los vértices con coste total mínimo y justificar la selección de aristas. El aprendizaje esperado es razonar sobre el método y justificar el resultado, no solo registrar una respuesta. Esta ficha enlaza el material disponible y señala sus límites para que se entienda qué permite comprobar.
