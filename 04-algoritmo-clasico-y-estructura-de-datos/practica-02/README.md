## En palabras simples

![En palabras simples · Guía para estudiantes](../../assets/readme-banners/en-palabras-simples.svg)

O describe un límite por arriba; Ω, uno por abajo; Θ, uno por ambos lados del mismo orden. Si un proceso hace `3n + 2` pasos, su crecimiento es lineal: lo que domina cuando n es grande es el término con n.

## Propósito

Usar definiciones y cotas para argumentar cómo se comporta una función cuando aumenta el tamaño de entrada.

## Mandato

La actividad solicita demostrar pertenencia a O, Ω y Θ, comparar funciones y reconocer sus clases de crecimiento.

## Qué se trabaja

Demostraciones de cotas asintóticas y comparaciones de crecimiento.

## Qué aporta esta actividad

Usar definiciones y cotas para argumentar cómo se comporta una función cuando aumenta el tamaño de entrada. El aprendizaje esperado es razonar sobre el método y justificar el resultado, no solo registrar una respuesta. Esta ficha enlaza el material disponible y señala sus límites para que se entienda qué permite comprobar.
