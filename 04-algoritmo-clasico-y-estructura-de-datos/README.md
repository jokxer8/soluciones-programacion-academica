## Recorrido de la materia

El curso avanza desde el análisis de crecimiento y las recurrencias hasta árboles, grafos y tablas hash. El recorrido conecta lo que se pide en cada actividad con el método que se aplica y el PDF que se conserva.

## Programa de la asignatura

El programa oficial organiza el curso en cinco unidades:

| Unidad | Contenidos principales |
|---|---|
| I. Análisis de algoritmos | Crecimiento, notaciones asintóticas, modelo RAM y coste temporal |
| II. Análisis de recurrencias | Sustitución, árbol de recursión y teorema maestro |
| III. Árboles | BST, AVL, rojo-negro, árboles B, de segmentos y Fenwick |
| IV. Tablas hash | Funciones hash, acceso directo, colisiones, encadenamiento y sondeo |
| V. Grafos | BFS, DFS, caminos mínimos, Prim, Kruskal, ordenamiento topológico y componentes fuertemente conectados |

El inventario consultado no identifica una práctica publicada para todos los temas del programa. La lista de contenidos no implica que estén resueltos en esta carpeta; [MATERIALES.md](MATERIALES.md) detalla lo localizado y lo pendiente.

## Estado y límites

**En revisión.** Las nueve prácticas tienen fichas de lectura. La Práctica 3 incluye un resumen del mandato obtenido del mapa e inventario disponibles, pero no se encontró el enunciado original ni una entrega. Los demás PDF están enlazados como entregas académicas; una etiqueta anterior como «solucionada» no constituye una validación independiente.

No se dispone de una revisión página por página de todas las respuestas ni de informes de ejecución de código para las prácticas. Las fichas explican el alcance que describen las fuentes, distinguen lo conocido de lo pendiente y evitan atribuir a la entrega resultados que no se han comprobado.
