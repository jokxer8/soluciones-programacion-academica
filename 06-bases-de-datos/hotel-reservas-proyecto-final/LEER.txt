PROYECTO FINAL: SISTEMA DE RESERVAS DE HOTEL
Kelvin Del Castillo, Gabriel Galasso y Camila Vasquez.

INSTALACION
1. Usar una instancia SQL Server de practica. HotelDB_Proyecto_Final.sql ELIMINA y recrea HotelDB.
2. Ejecutar Base de Datos/HotelDB_Proyecto_Final.sql.
3. Ejecutar Base de Datos/HotelDB_Fase1_Migracion.sql una vez, sobre la base nueva.
4. Opcional: ejecutar HotelDB_SeedData.sql una vez.
5. Ejecutar Base de Datos/HotelDB_Fase2_Contrasenas.sql antes de abrir la nueva aplicacion. En una base existente ejecutar solo Fase2, sin repetir esquema ni seed.
6. Abrir HotelReservas/HotelReservas.csproj en Visual Studio con .NET Framework 4.8 Developer Pack.
7. Restaurar packages.config mediante NuGet en la carpeta packages junto a HotelReservas.
8. Definir HOTELRESERVAS_CONNECTION_STRING para otra instancia de practica; sin esa variable se usa localhost con autenticacion de Windows.
9. Compilar y ejecutar.
