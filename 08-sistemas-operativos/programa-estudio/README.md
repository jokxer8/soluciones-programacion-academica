## Temas que aparecen en la carpeta de trabajo

El inventario de materiales y entregas cubre fundamentos y estructura de sistemas operativos; virtualización; instalación y administración de Windows; Shell y automatización; protección y mantenimiento; sistemas móviles, macOS y Linux; respaldos, sistemas de archivos y memoria; y administración básica de Windows Server y servicios de red.

Esta síntesis organiza la documentación publicada. Para los objetivos y unidades oficiales, consulta el PDF del programa.

## Cómo usar esta sección

El programa funciona como referencia curricular, mientras que cada [actividad](../actividades/README.md) enlaza la consigna o la evidencia disponible. La [matriz de competencias](../competencias/README.md) conecta esas actividades con los conocimientos que se documentan en este portafolio.
