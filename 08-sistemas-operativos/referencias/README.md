## Fuentes usadas durante la asignatura

La carpeta de trabajo incluye un programa de estudio, presentaciones de capítulos, una guía de instalación de Windows en VirtualBox, materiales sobre imágenes de sistemas operativos, recursos audiovisuales enlazados en las consignas y el libro *Sistemas Operativos Modernos*, de Andrew S. Tanenbaum.

El [programa de estudio](../programa-estudio/README.md) se incluye como documento curricular. Las fuentes bibliográficas y audiovisuales deben citarse en cada entrega según corresponda.

## Criterios de publicación

- Los PDF individuales se conservan como evidencia; los nombres de archivo se corrigieron para describir el contenido.
- Los nombres normalizados no sustituyen ni reescriben el contenido académico original.
- Los recursos externos se enlazan o citan; no se vuelve a publicar un libro completo de terceros.
- Los documentos de proyectos grupales se resumen aquí cuando incluyen identificadores personales de otros integrantes.
- La disponibilidad de un archivo no se interpreta como calificación ni aprobación académica.

## Atribución

Las actividades fueron elaboradas como parte de ISC-364 Sistemas Operativos I en PUCMM. Las actividades grupales se identifican como tales y las contribuciones personales se describen por separado.
