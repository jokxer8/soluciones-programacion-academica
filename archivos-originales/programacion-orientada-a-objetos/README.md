# Archivos Originales - Programación Orientada a Objetos

Esta carpeta conserva los archivos originales relacionados con la asignatura o área de Programación Orientada a Objetos.

Los documentos almacenados aquí funcionan como respaldo académico de ejercicios, prácticas, tareas o materiales utilizados como base para construir las soluciones profesionalizadas del repositorio.

---

## Objetivo de esta carpeta

Mantener una copia organizada de los documentos originales relacionados con programación orientada a objetos.

Estos archivos permiten conservar la trazabilidad entre el material académico inicial y las soluciones finales documentadas en la carpeta principal:

```text
02-programacion-orientada-a-objetos/
```

---

## Contenido esperado

Esta carpeta puede incluir archivos originales en diferentes formatos, tales como:

- TXT
- PDF
- DOCX
- Imágenes
- Archivos de código
- Enunciados de prácticas
- Tareas académicas
- Parciales o ejercicios evaluativos

---

## Temas relacionados

Los documentos originales de esta carpeta pueden incluir ejercicios sobre:

- Clases y objetos
- Constructores
- Encapsulación
- Propiedades
- Métodos
- Composición
- Herencia
- Polimorfismo
- Interfaces
- Clases abstractas

---

## Relación con las soluciones finales

Las soluciones finales y documentadas se encuentran en:

```text
02-programacion-orientada-a-objetos/
```

Allí cada ejercicio cuenta con:

```text
nombre-del-ejercicio/
├── README.md
└── solution.cs
```

---

## Nota

Los archivos de esta carpeta se conservan únicamente como respaldo académico.

Las versiones limpias, explicadas y profesionalizadas de los ejercicios están organizadas en la carpeta principal de Programación Orientada a Objetos.
