# Archivos Originales - Diseño y Análisis de Algoritmos

Esta carpeta conserva los archivos originales relacionados con la asignatura o área de Diseño y Análisis de Algoritmos.

Los documentos almacenados aquí funcionan como respaldo académico de ejercicios, prácticas, parciales o materiales utilizados como base para construir las soluciones profesionalizadas del repositorio.

---

## Objetivo de esta carpeta

Mantener una copia organizada de los documentos originales relacionados con algoritmos, estructuras de datos, recursividad, búsqueda, ordenamiento, programación dinámica y análisis de complejidad.

Estos archivos permiten conservar la trazabilidad entre el material académico inicial y las soluciones finales documentadas en la carpeta principal:

```text
03-diseno-y-analisis-de-algoritmos/
```

---

## Contenido esperado

Esta carpeta puede incluir archivos originales en diferentes formatos, tales como:

- TXT
- PDF
- DOCX
- Imágenes
- Archivos de código
- Enunciados de prácticas
- Parciales o tareas académicas

---

## Relación con las soluciones finales

Las soluciones finales y documentadas se encuentran en:

```text
03-diseno-y-analisis-de-algoritmos/
```

Allí cada ejercicio cuenta con:

```text
nombre-del-ejercicio/
├── README.md
└── solution.cs
```

---

## Nota

Los archivos de esta carpeta se conservan únicamente como respaldo académico.

Las versiones limpias, explicadas y profesionalizadas de los ejercicios están organizadas en la carpeta principal de Diseño y Análisis de Algoritmos.
