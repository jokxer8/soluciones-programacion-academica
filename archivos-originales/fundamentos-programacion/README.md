# Archivos Originales - Fundamentos de Programación en C#

Esta carpeta conserva los archivos originales relacionados con la asignatura o área de Fundamentos de Programación trabajada principalmente con C#.

Los documentos almacenados aquí funcionan como respaldo académico de ejercicios, prácticas, parciales o materiales utilizados como base para construir las soluciones profesionalizadas del repositorio.

---

## Objetivo de esta carpeta

Mantener una copia organizada de los documentos originales relacionados con los fundamentos de la programación estructurada.

Estos archivos permiten conservar la trazabilidad entre el material académico inicial y las soluciones finales documentadas en la carpeta principal:

```text
01-fundamentos-programacion/
```

---

## Contenido esperado

Esta carpeta puede incluir archivos originales en diferentes formatos, tales como:

- TXT
- PDF
- DOCX
- Imágenes
- Archivos de código
- Enunciados de prácticas
- Parciales o tareas académicas

---

## Temas relacionados

Los documentos originales de esta carpeta pueden incluir ejercicios sobre:

- Entrada y salida de datos
- Variables
- Tipos de datos
- Condicionales
- Ciclos
- Arreglos
- Cadenas de texto
- Métodos
- Validaciones
- Búsqueda secuencial
- Ejercicios básicos de lógica

---

## Relación con las soluciones finales

Las soluciones finales y documentadas se encuentran en:

```text
01-fundamentos-programacion/
```

Allí cada ejercicio cuenta con:

```text
nombre-del-ejercicio/
├── README.md
└── solution.cs
```

---

## Nota

Los archivos de esta carpeta se conservan únicamente como respaldo académico.

Las versiones limpias, explicadas y profesionalizadas de los ejercicios están organizadas en la carpeta principal de Fundamentos de Programación.
