Un elefante decidió visitar a su amigo. Resultó que la casa del elefante se encuentra en el punto 0 y la casa de su amigo se encuentra en el punto x(x > 0) de la línea de coordenadas. En un paso, el elefante puede moverse 1, 2, 3, 4 o 5 posiciones hacia adelante. Determine cuál es el número mínimo de pasos que necesita hacer para llegar a la casa de su amigo.

Entrada
La primera línea de la entrada contiene un número entero x (1 ≤ x ≤ 1 000 000) — La coordenada de la casa del amigo.

Salida
Imprima el número mínimo de pasos que el elefante necesita hacer para llegar desde el punto 0 señalar x.

Ejemplos
entrada
5
salida
1
entrada
12
salida
3





using System;

class Program
{
    static void Main()
    {
        int x = int.Parse(Console.ReadLine());
        int steps = (x + 4) / 5;
        Console.WriteLine(steps);
        Console.ReadLine();
    }
}
