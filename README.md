# Soluciones de Programación Académica

Este repositorio reúne problemas resueltos de programación desarrollados durante mi formación académica en Ingeniería Ciencias de la Computación.

El objetivo principal es documentar mi evolución técnica en lógica de programación, programación orientada a objetos, estructuras de datos, análisis de algoritmos y resolución de problemas mediante código.

## Objetivo del repositorio

Organizar y presentar de forma profesional ejercicios, prácticas y soluciones desarrolladas en diferentes etapas de mi formación universitaria y técnica.

Este repositorio servirá como evidencia de práctica constante, desarrollo de pensamiento lógico y aplicación progresiva de conceptos de programación.

## Áreas incluidas

### 01 - Fundamentos de la Programación

Problemas relacionados con:

- Entrada y salida de datos
- Variables y tipos de datos
- Operadores
- Condicionales
- Bucles
- Arreglos
- Funciones
- Manejo básico de archivos
- Lógica de programación

### 02 - Programación Orientada a Objetos

Problemas relacionados con:

- Clases y objetos
- Constructores
- Encapsulamiento
- Herencia
- Polimorfismo
- Interfaces
- Clases abstractas
- Relaciones entre clases
- Organización de código orientado a objetos

### 03 - Diseño y Análisis de Algoritmos

Problemas relacionados con:

- Recursividad
- Búsqueda secuencial
- Búsqueda binaria
- Algoritmos de ordenamiento
- Complejidad algorítmica
- Notación Big O
- Optimización de soluciones
- Análisis de eficiencia

## Tecnologías y lenguajes utilizados

- C#
- C++
- C
- SQL
- Pseudocódigo
- Aplicaciones de consola
- Archivos de texto como base documental inicial
