# Análisis de Cadena de Texto

## Descripción del problema

Este ejercicio consiste en leer una frase ingresada por el usuario y realizar diferentes análisis sobre su contenido.

El programa determina:

- Cantidad de caracteres.
- Cantidad de palabras.
- Cantidad de vocales.
- Cantidad de consonantes.
- Texto invertido.

## Objetivo

Aplicar conceptos fundamentales de programación utilizando cadenas de texto, ciclos, condicionales y métodos.

## Entrada

El programa solicita al usuario una frase o texto.

Ejemplo:

```text
Ingrese una frase: Programar en C# es importante
```

## Salida

El programa muestra un resumen del análisis realizado.

Ejemplo:

```text
Cantidad de caracteres: 29
Cantidad de palabras: 5
Cantidad de vocales: 10
Cantidad de consonantes: 14
Texto invertido: etnatropmi se #C ne ramargorP
```

## Conceptos aplicados

- Entrada de datos
- Cadenas de texto
- Métodos
- Ciclos
- Condicionales
- Validación básica
- Manipulación de caracteres
- Separación de responsabilidades

## Análisis del algoritmo

El programa recibe una frase y utiliza varios métodos para analizarla.

Cada método realiza una tarea específica: contar palabras, contar vocales, contar consonantes o invertir el texto.

Esto permite organizar mejor el código y evitar que toda la lógica esté concentrada en el método principal.

## Complejidad

- Tiempo: O(n)
- Espacio: O(n)

Donde n representa la cantidad de caracteres de la frase.

## Lenguaje utilizado

C#
