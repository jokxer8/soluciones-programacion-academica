# 01 - Fundamentos de la Programación

Esta carpeta contiene problemas resueltos relacionados con los fundamentos de la programación.

## Temas principales

- Entrada y salida de datos
- Variables y tipos de datos
- Operadores
- Condicionales
- Bucles
- Arreglos
- Funciones
- Manejo básico de archivos
- Lógica de programación

## Objetivo

Organizar ejercicios académicos que sirvieron como base para desarrollar lógica de programación y resolver problemas mediante código.
