# 03 - Diseño y Análisis de Algoritmos

Esta carpeta contiene problemas resueltos relacionados con el diseño, análisis y optimización de algoritmos.

## Temas principales

- Recursividad
- Búsqueda secuencial
- Búsqueda binaria
- Algoritmos de ordenamiento
- Análisis de complejidad
- Notación Big O
- Estructuras de datos
- Optimización de soluciones
- Comparación de eficiencia entre algoritmos
- Resolución de problemas complejos

## Objetivo

Organizar ejercicios académicos enfocados en el razonamiento algorítmico, el análisis de eficiencia y la construcción de soluciones optimizadas para problemas computacionales.
