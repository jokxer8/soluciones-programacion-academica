## En palabras simples

![En palabras simples · Guía para estudiantes](../../assets/readme-banners/en-palabras-simples.svg)

El simulador es una herramienta para repasar. Responde primero sin mirar material, identifica qué concepto confundiste y vuelve a la unidad correspondiente. Sirve para practicar y no es un examen oficial.

## Simulador de exámenes ICC-341

El archivo HTML contiene tres bancos de práctica con **50 preguntas cada uno**. Cada intento selecciona **30 preguntas sin repetición**, mezcla las preguntas y el orden de las opciones, permite navegar antes de entregar y muestra la nota junto con una revisión de respuestas.

- [Abrir o descargar el simulador](examenes-icc341.html)

### Uso

1. Descarga el archivo HTML o ábrelo desde GitHub.
2. Si el navegador muestra el código fuente, descarga el archivo y ábrelo localmente en un navegador.
3. Selecciona uno de los bancos, responde y entrega el intento.
4. Revisa las respuestas incorrectas y vuelve al inicio para practicar otra vez.

El simulador indica que funciona sin conexión. Está pensado como recurso de estudio y no reproduce una evaluación oficial ni sustituye las presentaciones de clase.

### Cobertura

La página describe tres bancos de 50 preguntas. Para la unidad 6 aclara que no había material de clase adjunto y que sus preguntas sobre RUP se basan en las fases y disciplinas estándar del proceso. Considera ese segmento una práctica general y contrástalo con el contenido indicado por el docente.
