Los documentos disponibles describen planificación de sistemas de información usando Azure DevOps Basic. Se presentan como evidencias de diseño y organización de requisitos; los PDF no demuestran por sí solos que una instancia de Azure DevOps esté activa o que todas las tareas se hayan completado.

## SIGERH

**Sistema Integral de Gestión de Recursos Humanos.** La primera práctica organiza el trabajo mediante objetivos amplios, módulos funcionales y tareas concretas, en una jerarquía de **2 Epic, 8 Issue y 20 Task**.

La guía documenta la planificación de requisitos del sistema y su relación con ICC-341-T. El documento indica que la entrega de la práctica se vincula con una URL de proyecto de Azure DevOps; no se localizó una URL pública verificable dentro de los archivos revisados.

- [Primera práctica SIGERH (PDF)](sigerh-practica-01.pdf)

## KHuman

**KHuman** es un plan de sistema de Recursos Humanos. La guía visual explica la jerarquía de trabajo, la relación entre módulos, requerimientos y campos, así como la planificación y el seguimiento de 30 elementos conectados.

El documento ofrece una ruta para comprender el propósito del proyecto y revisar sus elementos de trabajo. Se publica como guía de estudio, no como evidencia de que el sistema esté implementado.

- [Guía visual KHuman (PDF)](khuman-guia-visual.pdf)
