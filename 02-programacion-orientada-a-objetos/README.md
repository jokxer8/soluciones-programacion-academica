# 02 - Programación Orientada a Objetos

Esta carpeta contiene problemas resueltos relacionados con la programación orientada a objetos.

## Temas principales

- Clases y objetos
- Constructores
- Encapsulamiento
- Propiedades y métodos
- Herencia
- Polimorfismo
- Interfaces
- Clases abstractas
- Relaciones entre clases
- Organización de código orientado a objetos

## Objetivo

Organizar ejercicios académicos que permitieron aplicar los principios de la programación orientada a objetos para diseñar soluciones más estructuradas, reutilizables y mantenibles.
